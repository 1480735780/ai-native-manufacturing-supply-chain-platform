## 三、关键风险

1. **导出数据错误**：`DefPlatMapper.h:35-36` 将查询结果第 1 列写入 `platform_code`、第 2 列写入 `platform_name`，而 SQL 是 `SELECT platform_name, platform_code`，导出结果两列颠倒。
2. **映射脆弱**：`PlcDAO::selectById` 使用 `SELECT *`，Mapper 依赖列顺序；表结构变更会导致字段错位。
3. **数据模型缺口**：`ba_platform.platform_del` 字段存在但未使用（`zowms.sql:497-511`）；`wm_plat_io` 无外键/索引（`zowms.sql:3239-3260`）；`ba_platform`（utf8）与 `wms_plc`（utf8mb4）字符集不一致。
4. **契约不一致**：月台计划 XML namespace 是 `com.zeroone.star.outbound.mapper.WmPlatIoMapper`，而 Java Mapper 包是 `com.zeroone.star.outgoodsmanage.mapper.WmPlatIoMapper`（`WmPlatIoMapper.xml:3` vs `WmPlatIoMapper.java:1`）。
5. **部署耦合**：月台导出 URL 直接使用 `dbHost:8888`，强依赖 FastDFS/Nacos 配置，且未做配置化与失败降级。
6. **基线风险**：子仓库 `zero-one-10wms` 当前在 `dev` 且有未提交修改；后续实现前必须先确认基线，避免把无关改动混入本分支。
